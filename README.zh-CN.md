# DSH 远程控制 [English](README.md) | **简体中文**

用手机接管 DeepSeek Harness：电脑端点「手机连接」后扫码，电脑进入接管遮罩，手机可解锁、锁屏、查看文件。局域网模式功能完整；远程模式通过内置 Cloudflare 隧道，手机用流量也能连。

## 功能

- 桌面右下角悬浮按钮 → 选择 **本地（局域网）** 或 **远程（外网）**
- **本地**：同一 WiFi 直连，不经过公网，多会话/多项目，功能不限
- **远程**：外网可用，免费版限单会话，内置 Cloudflare 快速隧道（无需单独安装）
- 桌面生成当前模式的二维码（公网地址只以二维码呈现，不显示文字）
- 桌面接管遮罩；解锁码由手机生成（TOTP，离线可用）
- 连续输错 3 次变黄警告
- 手机一键锁定 Windows，锁头跟随真实锁屏状态
- 手机断开约 15 秒后遮罩自动解除（无需验证码）
- 手机文件浏览、新建工作区（选盘符+文件夹名）、手机端紧凑顶栏

## 安装

```bash
dsh plugin --profile <profile> add github:zhirai-tech/dsh-remote-control#v0.2.0
```

在 profile 的 `cordis.patch.yml` 启用：

```yaml
- id: remote-control
  config:
    enabled: true
    port: 7466
```

重启 Harness，桌面右下角出现手机按钮。

## 使用

1. 点手机按钮 → 选「本地」或「远程」
2. 桌面显示二维码（远程需等公网地址生成）
3. 手机扫码，电脑自动进入遮罩
4. 手机生成解锁码，电脑输入后解除
5. 手机断开约 15 秒后遮罩自动解除

每次启动访问密钥都会更换，旧二维码失效。
