# DSH Remote Control — 设计说明（v0.1）

## 目标
手机通过浏览器接管 Harness：局域网优先直连，二期用花生壳映射公网并生成二维码；桌面端在被接管时显示遮罩，手机可一键锁定电脑。

## 一期范围（LAN）
1. 插件在 `0.0.0.0:7466` 启动本地服务，反向代理到 `127.0.0.1:62186`；
2. 认证：插件用 `ctx.connection.authenticatedUrl()` 取得带 token 的本机地址，向本机换取 dsh-auth cookie，代理时注入；代理改写 Host/Origin 为 127.0.0.1:62186；
3. 手机端：代理注入移动样式（隐藏桌宠/实时条）与浮动条（解锁码、锁定电脑、断开）；
4. 桌面端：客户端插件全屏遮罩，手机连接后显示，输入解锁码解除；
5. 解锁码：配对时生成共享密钥；手机端按 TOTP（60s）计算；桌面本地校验（±5 分钟窗口），离线可用；
6. 一键锁屏：手机端调用插件接口 → host 执行 `rundll32.exe user32.dll,LockWorkStation`；
7. 停止：关闭开关 / Harness 退出 / 闲置超时，服务停止、遮罩解除。

## 二期范围（花生壳）
- 设置里填花生壳映射域名，映射到本机 7466；
- 插件检测公网地址连通性，把域名包装成二维码显示在桌面与手机；
- 验证码逻辑与一期完全一致（同一共享密钥）。

## 安全
- 默认关闭；启动需用户在设置里显式开启；
- 配对码一次性，配对后存共享密钥；
- 解锁码只显示在手机，桌面不显示；
- 遮罩只作用于 Harness 窗口，系统级安全依赖锁屏；
- 代理仅注入本机认证，不暴露 Harness token 给手机。

## 非目标
- 不改 Harness 核心；
- 不做系统级键盘锁/绝对只读；
- 一期不做账号体系与云中转。
